### Task 2: Реализация

- [x] В `textkit/core.py` добавить:

```python
def shout(text: str) -> str:
    """Uppercase text and make sure it ends with a single exclamation mark.

    Example:
        >>> shout("hello")
        'HELLO!'
    """
    up = text.upper()
    return up if up.endswith("!") else up + "!"
```
