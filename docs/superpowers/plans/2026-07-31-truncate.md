### Task 2: Реализация

- [ ] В `textkit/core.py` добавить:

```python
def truncate(text: str, width: int) -> str:
    """Truncate text to width chars, ending with an ellipsis when cut."""
    if len(text) <= width:
        return text
    return text[: width - 1] + "…"
```
