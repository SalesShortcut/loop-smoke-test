# Spec: slugify — URL-безопасные слаги для textkit

## Цель

Добавить в `textkit` функцию `slugify(text: str) -> str`, превращающую
произвольную строку в URL-безопасный слаг.

## Требования

1. Результат содержит только `a-z`, `0-9` и дефис `-`.
2. Буквы приводятся к нижнему регистру.
3. Любая последовательность прочих символов (пробелы, пунктуация) заменяется
   на один дефис.
4. Ведущие и хвостовые дефисы обрезаются.
5. Пустая строка и строка без допустимых символов дают `""`.
6. Только стандартная библиотека Python; никаких новых зависимостей.

## Примеры

| Вход | Выход |
|---|---|
| `"Hello, World!"` | `"hello-world"` |
| `"  Много   пробелов  "` | `""` (кириллица не транслитерируется) |
| `"Python 3.12 rocks"` | `"python-3-12-rocks"` |

## Вне скоупа

Транслитерация не-ASCII символов, настройка разделителя.
