# truncate() Design

## Цель

Добавить в textkit функцию `truncate(text: str, width: int) -> str` — обрезка строки до заданной ширины с многоточием.

## Требования (обязательные)

1. Если `len(text) <= width` — вернуть `text` без изменений.
2. Иначе — вернуть первые `width - 1` символов `text` плюс символ `…` (U+2026, одиночный символ), итоговая длина результата ровно `width`.
3. **Валидация входа: при `width <= 0` функция ОБЯЗАНА поднимать `ValueError` с сообщением `"width must be positive"`.** Тихий возврат пустой строки или многоточия при некорректной ширине недопустим — это скрывает ошибку вызывающего кода.
4. Функция экспортируется из пакета: `from textkit import truncate`.

## Не в скоупе

- Обрезка по границам слов.
- Настраиваемый символ многоточия.
