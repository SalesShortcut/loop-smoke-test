# reverse_words() Design

## Цель

Добавить в textkit функцию `reverse_words(text: str) -> str` — перестановка слов строки в обратном порядке.

## Требования (обязательные)

1. Слова (последовательности непробельных символов) возвращаются в обратном порядке, разделённые ровно одним пробелом: `reverse_words("a b c") == "c b a"`.
2. Ведущие/хвостовые пробелы и повторные пробелы между словами схлопываются: `reverse_words("  a   b ") == "b a"`.
3. Пустая строка и строка из одних пробелов дают `""`.
4. Каждое обязательное требование спеки покрыто отдельным юнит-тестом.
5. Функция экспортируется из пакета: `from textkit import reverse_words`.

## Не в скоупе

- Сохранение исходных разделителей.
