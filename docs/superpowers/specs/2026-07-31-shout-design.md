# shout() Design

## Цель

Добавить в textkit функцию `shout(text: str) -> str` — «крик»: верхний регистр плюс восклицательный знак.

## Требования (обязательные)

1. `shout("hello") == "HELLO!"` — текст в верхнем регистре, в конце добавлен ровно один `!`.
2. Если текст уже заканчивается на `!`, второй не добавляется: `shout("stop!") == "STOP!"`.
3. Функция экспортируется из пакета: `from textkit import shout`.

## Не в скоупе

- Обработка других знаков препинания.
