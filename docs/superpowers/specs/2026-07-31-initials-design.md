# Spec: initials — инициалы из имени

## Цель

Добавить в `textkit` функцию `initials(name: str) -> str`, возвращающую
инициалы имени.

## Требования

1. Из каждого слова (разделение по пробелам) берётся первый символ,
   приводится к верхнему регистру, после каждого ставится точка.
2. Инициалы соединяются без пробелов: `"ada lovelace"` → `"A.L."`.
3. Пустая строка и строка из одних пробелов дают `""`.
4. Слова из одного символа обрабатываются так же: `"a b"` → `"A.B."`.
5. Только стандартная библиотека Python.

## Примеры

| Вход | Выход |
|---|---|
| `"ada lovelace"` | `"A.L."` |
| `"  Grace   Brewster Murray  Hopper "` | `"G.B.M.H."` |
| `""` | `""` |

## Вне скоупа

Обработка дефисов внутри слов, не-буквенные первые символы.
